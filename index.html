Notes for developer

  • Placement: Profile secondary button after Blocked users / before Support — same variant as My groups. Opens AppStack NotificationSettings.
  • Sections: Push first, Email second. Only three push kinds (CHAT-6). No competitor extras.
  • Defaults: push all on; email off. Missing prefs row = allow push / email false after backfill.
  • Toggles: optimistic switch rows like AnalyticsToggleSection; shared save-error banner OK if cleaner than per-toggle.
  • OS denied: top hint + Open settings only — reuse CHAT-6 soft-ask denial path; do not re-prompt OS from this screen.
  • Consent: signup + Google first-accept checkboxes default unchecked; Create/Agree never require them; write prefs after session; failure non-blocking.
  • Out of mock: unsubscribe HTML page, ops send Edge, animation timing — implementer call. Core hierarchy above is sealed.
